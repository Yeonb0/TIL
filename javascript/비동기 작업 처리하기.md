## ✨ What I Learned
### 1. 콜백 함수
- 콜백 함수로 비동기 결과 값을 함수 밖에서 이용
- 콜백 지옥에 빠질 수 있음

### 2. Promise
- JS 의 내장 객체
- 비동기 작업 랩핑
	- 비동기 작업 실행 / 상태 관리 / 결과 저장 / 병렬 실행 / 다시 실행 등
- 상태
	- 대기 (Pending) : 아직 작업이 완료되지 않은 상태
	- 성공 (Fulfilled) : 비동기 작업이 성공적으로 마무리 된 상태
	- 실패 (Rejected) : 비동기 작업이 실패한 상태
	- 해결 (resolve) : 대기 → 성공
	- 거부 (reject) : 대기 → 실패


## 💠 Example / Code

```jsx
// 1-1 콜백 함수로 비동기 작업을 하는 함수의 결과값을 함수 외부에서 이용
function add(a, b, callback) {
	setTimeout(() => {
		const sum = a + b;  // 3
		callback(sum);
	}, 3000);
}

add(1, 2, (value) => {
	console.log(value);
});

// 1-2 음식을 주문하는 상황
// 비동기 작업 결과를 또다른 비동기 작업으로 사용
function orderFood(callback) {
	setTimeout(() => {
		const food = "떡볶이";
		callback(food);
	}, 3000)
}

function cooldownFood(food)  {
	setTimeout(() => {
		const cooldownedFood = `식은 ${food}`;
		callback(cooldownedFood);
	}, 2000)
}

function freezeFood(food) {
	setTimeout(() => {
		const freezedFood = `냉동된 ${food}`;
		callback(freezedFood);
	}, 1500)
}

orderFood(() => {
	console.log(food);
	
	cooldownFood(food, (cooldownedFood) => {
		console.log(cooldownedFood);
		
		freezeFood(cooldownedFood, (freeezedFood) => {
			console.log(freezedFood);
		});
	});
})

// 2 promise 
const promise = new Promise((resolve, reject) => {
	// 비동기 작업 실행하는 함수
	//executor
	
	setTimeout(() => {
		const num = 10;
		
		if (typeof num === "number") {
			resolve(num + 10); // PromiseState & PromiseResult 설정
		} else {
			reject("num이 숫자가 아닙니다"); // PromiseState & PromiseResult 설정
		}
	}, 2000);
})

// then 메서드
// -> 그 후에


```
