# JavaScript Array Methods

> 2026-05-11 (Mon)

## ✨ What I Learned

- JavaScript 배열은 목적에 따라 **요소 조작 / 순회 & 탐색 / 배열 변형** 세 가지 범주의 메소드를 제공한다.
- `push` / `pop` 은 배열 뒤쪽, `unshift` / `shift` 는 배열 앞쪽을 조작, 앞쪽 조작이 더 느린 이유는 나머지 요소를 모두 재인덱싱해야 하기 때문이다.
- `slice` / `concat` 은 **원본을 변경하지 않고** 새 배열을 반환하는 반면, `sort` 는 **원본 배열 자체를 변경**한다. `toSorted` 는 원본을 유지한 채 정렬된 새 배열을 반환한다.
- `indexOf` 는 얕은 비교(`===`)만 수행하므로 객체 검색엔 `findIndex` / `find` 를 사용해야 한다.
- `filter` 는 조건을 만족하는 요소들의 새 배열, `map` 은 각 요소를 변환한 새 배열을 반환한다.

## 💠 Example / Code

```javascript
// ── 요소 조작 ──────────────────────────────────────────
const arr = [1, 2, 3];

arr.push(4, 5);       // [1, 2, 3, 4, 5]  — 반환값: 5 (length)
arr.pop();            // [1, 2, 3, 4]     — 반환값: 5 (제거된 요소)
arr.unshift(0);       // [0, 1, 2, 3, 4]  — 반환값: 5 (length)
arr.shift();          // [1, 2, 3, 4]     — 반환값: 0 (제거된 요소)

const sliced = arr.slice(1, 3);   // [2, 3]  원본 불변
const merged = arr.concat([5, 6]);// [1, 2, 3, 4, 5, 6]  원본 불변

// ── 순회 & 탐색 ────────────────────────────────────────
const nums = [10, 20, 30];

nums.forEach((item, idx) => console.log(idx, item)); // 각 요소 순회
nums.includes(20);            // true
nums.indexOf(30);             // 2  (없으면 -1)

const users = [{ name: "Alice" }, { name: "Bob" }];
users.findIndex((u) => u.name === "Bob"); // 1  — 객체 탐색 가능
users.find((u) => u.name === "Alice");    // { name: "Alice" }

// ── 배열 변형 ──────────────────────────────────────────
const people = [
  { name: "Alice", hobby: "tennis" },
  { name: "Bob",   hobby: "reading" },
  { name: "Carol", hobby: "tennis" },
];

const tennisPlayers = people.filter((p) => p.hobby === "tennis");
// [{ name: "Alice", ... }, { name: "Carol", ... }]

const names = people.map((p) => p.name);
// ["Alice", "Bob", "Carol"]

const scores = [30, 10, 20];
scores.sort((a, b) => a - b);           // [10, 20, 30]  원본 변경!
const sorted = scores.toSorted((a, b) => b - a); // [30, 20, 10]  원본 유지

["hi", "I'm", "Claude"].join(" ");      // "hi I'm Claude"
```

## ✒️ Usage

- **데이터 필터링**: API 응답에서 조건에 맞는 항목만 추려 화면에 렌더링할 때 (`filter`)
- **데이터 변환**: 객체 배열에서 특정 필드만 추출하거나 값을 가공해 새 배열을 만들 때 (`map`)
- **요소 존재 확인**: 선택된 ID가 목록에 있는지 빠르게 체크할 때 (`includes`, `findIndex`)
- **정렬 & 결합**: 테이블 정렬 기능 구현 시 원본 보존이 필요하면 `toSorted`, URL 파라미터나 CSV 생성 시 `join`
